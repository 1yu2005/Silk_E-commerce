 `const`、`var`，还有配套的 `let` 是 JS 声明变量的三个关键字：

### var

早期 JS 声明变量的方式

- **函数作用域**（不是块作用域）
- 允许重复声明同一个变量
- 存在**变量提升**，提升后值是 `undefined`
- 可以先使用，后声明（容易出bug）

```
console.log(a); // undefined
var a = 10;
var a = 20; // 允许重复声明
```

### const

用来声明**常量**

- **块级作用域**（`{}` 内部有效）

- **必须在声明时赋值**，不能后续重新赋值

- 不能重复声明

- 也有变量提升，但存在**暂时性死区（TDZ）**，在声明前不能访问

  > ⚠️ 重点：const 不是保证对象/数组内容不变，只是**变量引用地址不能改**

```
const num = 100;
num = 200; // ❌ 报错，不能重新赋值

const arr = [1,2,3];
arr.push(4); // ✅ 可以修改数组里面的内容，引用没变
```

### let（顺带对比，日常开发最常用）

声明可变变量

- **块级作用域**
- 不能重复声明
- 暂时性死区，声明前不能访问

```
let b = 1;
b = 2; // ✅ 可以修改
```

## 简单总结

| 关键字 | 作用域     | 能否重赋值 | 能否重复声明 | 提升           |
| ------ | ---------- | ---------- | ------------ | -------------- |
| var    | 函数作用域 | ✅          | ✅            | 提升到函数顶部 |
| let    | 块级作用域 | ✅          | ❌            | 提升，TDZ      |
| const  | 块级作用域 | ❌          | ❌            | 提升，TDZ      |

✅ 开发推荐：优先 `const`，确定后面要修改值的时候再用 `let`，**尽量不要用 var**。
