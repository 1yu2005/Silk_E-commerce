运行环境：是指代码正常运行所需的必要环境

JS是一门编程语言，Node.js 是js的一种运行环境
==Node.js是在**服务器端**运行的**JavaScript运行时环境**，而**客户端中的JS**是在**浏览器**中运行的。==

> **客户端（Client）**：<u>发起请求、面向用户的一侧。通常是用户设备上的软件</u>，比如浏览器、手机 App、桌面程序。它<u>负责展示界面、接收用户操作，并向服务器发请求。</u>
>
> **服务器端（Server）**：<u>接收请求、处理业务、返回结果的一侧</u>。它通常运行在服务器机器、云主机、容器里，也可以在你本机跑一个本地服务。它<u>负责数据库访问、权限校验、业务逻辑、接口响应等。</u>

==JavaScript的运行环境汇总：==  

- **浏览器类：**   前端开发

  例如 Chrome浏览器（v8引擎+浏览器内置的各种API 如 DOM/BOM)

  - v8引擎负责解析和执行JavaScript代码。  ps：不同浏览器有不同的引擎
  - 内置API 是由运行环境提供的特殊接口,只能在所属的运行环境中被调用。

- **服务器端/命令行类：**  后端开发

  例如 Node.js（V8 引擎 + Node.js 内置 API，如 `fs`、`http`、`path`、`process`） 

  - V8 引擎负责解析和执行 JavaScript 代码。
  - Node.js 内置 API 由 Node.js 运行环境提供，只能在 Node.js 中被调用，例如 `fs.readFile()`、`http.createServer()`、`process.env`。
  - Node.js 环境**没有 DOM/BOM**，不能直接操作网页；但它可以读写文件、创建网络服务器、访问进程信息等。
  - Node.js 还通过 `libuv` 提供事件循环和非阻塞 I/O，使 JavaScript 能处理文件、网络等服务器端任务。

- **其他 JavaScript 宿主环境：例如 Deno、Bun、Electron、小程序、React Native 等**

- **共同规律：==JavaScript 运行环境 ≈ JavaScript 引擎 + 宿主环境 API + 事件循环/任务调度等基础设施==** ⭐⭐⭐⭐⭐

  - **ECMAScript 核心语法一致**：变量、函数、对象、数组、`Promise`、`class` 等语言核心在不同环境中基本一致。
  - **宿主 API 决定能力边界**：浏览器提供 `document`、`window`、`fetch` 等；Node.js 提供 `fs`、`http`、`process` 等。
  - ==**内置 API 不能跨环境直接调用**==：浏览器里没有 `fs`，Node.js 里没有 `document`。同一段 JS 在浏览器和 Node.js 中表现不同，就是因为运行环境提供的 API 不同。
  - 如果需要跨环境复用代码，通常要靠适配层、打包工具、polyfill 或条件判断来处理环境差异。

==**JavaScript 是语言核心，运行环境负责“执行语言”并“提供能力”。浏览器和 Node.js 都能运行 JS，但前者提供网页 API，后者提供服务器端/系统级 API，所以🍋‍🟩🍋‍🟩🍋‍🟩同一门语言在不同环境中能做的事不同🍋‍🟩🍋‍🟩🍋‍🟩。**==

# 二、fs 文件系统模块



## 1. 什么是fs文件系统模块

fs 模块是 Node.js官方提供的、用来操作文件的模块。它提供了一系列的方法和属性,用来满足用户对文件的操作需求。

例如:

●` fs.readFile()`方法,用来读取指定文件中的内容

● `fs.writeFile()`方法,用来向指定的文件中写入内容

导入fs模块：

```javascript
const fs = require('fs')
```



## 2.fs.readFile()

```javascript
fs.readFile(path[, options], callback)
```

参数1:必选参数,字符串,表示文件的路径。

参数2:可选参数,表示以什么编码格式来读取文件。

参数3:必选参数,文件读取完成后,通过**回调函数**拿到读取的结果。



示例：以utf8的编码格式,读取指定文件的内容,并打印err和dataStr的值:

```javascript
// 1.导入 fs 模块，来操作文件
const fs = require('fs')

// 2.调用fs.readFile方法，读取文件中的内容
//   参数1：读取文件的存放路径
//   参数2：读取文件时侯采用的编码格式，一般默认指定 utf8
//   参数3：回调函数，用于处理读取文件完成后的结果（拿到读取失败和成功的结果 err dataStr）
fs.readFile('./file/1.txt', 'utf8', (err, dataStr) => {
    console.log(err)  // 打印读取失败的结果  
    console.log("-----------------")
    console.log(dataStr)  // 打印读取成功的结果
})

```

**如果读取成功，则 err 的值为 null**
**如果读取失败，则 err 的值为 错误对象，dataStr 的值为 underfined**

## 3.fs.writeFile()的语法格式

```
fs.writeFile(file, data[, options], callback)
```

参数1:必选参数,需要指定一个文件路径的字符串,表示文件的存放路径。

参数2:必选参数,表示要写入的内容。

参数3:可选参数,表示以什么格式写入文件内容,默认值是utf8。

参数4:必选参数,文件写入完成后的**回调函数**。



示例：

```javascript
// 1.导入 fs 模块，来操作文件
const fs = require('fs')

//2. 调用 fs.writeFile()方法,写入文件的内容
//   参数1:表示文件的存放路径
//   参数2:表示要写入的内容
//   参数3:回调函数

fs.writeFile('./file/2.txt', 'hello node', function(err) {
    if(err) {
       return console.log('文件写入失败'+err.message)
    }
    console.log("文件写入成功")
})
```

**如果文件写入成功  err 值等于 null**

**如果文件写入失败，则 err 的值等于一个 错误对象**



## 4.路径动态拼接的问题

在使用fs模块操作文件时,如果提供的操作路径是以/或 .. /开头的相对路径时,很容易出现路径动态拼接错误的问题。

原因:代码在运行的时候,会以执行node命令时所处的目录,动态拼接出被操作文件的完整路径。

解决方案:在使用fs模块操作文件时,直接提供完整的路径,不要提供./或 .. /开头的相对路径,从而防止路径动态拼接的问题。

提供完成路径的方法：直接在代码中填入 绝对路径；**`__dirname` 表示当前代码文件所处的目录**

示例：

```javascript
// __dirname 表示当前文件所处的目录
// console.log(_dirname)
const fs = require('fs')

fs.readFile(__dirname + '/file/1.txt', 'utf8', (err, dataStr) => {
    if(err) {
        return console.log('文件读取失败'+err.message)
    }
    console.log("文件读取成功" + dataStr)
})
```



# 三、path路径模块

## 1. 什么是 path 路径模块

path 模块是Node.js官方提供的、用来**处理路径的模块**。它提供了一系列的方法和属性,用来满足用户对路径的处理
需求。

例如:

● path.join()方法,用来将多个路径片段拼接成一个完整的路径字符串

● path.basename()方法,用来从路径字符串中,将文件名解析出来

导入：

```javascript
const path = require('path')
```



## 2.path.join()的语法格式

使用path.join()方法,可以**把多个路径片段拼接为完整的路径字符串**,语法格式如下:

```
path. join([ ... paths])
```

参数解读:

● ... paths <string>路径片段的序列

● 返回值 :< string>



示例：

```javascript
const pathStr = path. join('/a', '/b/c',' .. /','./d', 'e')   // ../ 会抵消上一层路径
console.log(pathStr) // \a\b\dle

const pathStr2 = path. join(_dirname, './files/1.txt')
console.log(pathStr2)//输出 当前文件所处目录\files\1.txt
```

**注意**:今后凡是涉及到路径拼接的操作,都要使用path.join()方法进行处理。不要直接使用+进行字符串的拼接。

```javascript
const fs = require('fs')
const path = require('path')

fs.readFile(path.join(__dirname,'/file/1.txt'), 'utf8', (err, dataStr) => {
    if(err) {
        return console.log('文件读取失败'+err.message)
    }
    console.log("文件读取成功" + dataStr)
})
```



## 3.path.basename()的语法格式

使用path.basename()方法,**可以获取路径中的最后一部分,经常通过这个方法获取路径中的文件名**,语法格式如下:

```
path.basename(path[, ext])
```

参数解读:

● path<string>必选参数,表示一个路径的字符串

● ext<string>可选参数,表示文件扩展名

● 返回 :< string>表示路径中的最后一部分



示例：

```javascript
const path = require('path')

const fpath='/a/b/c/index.html'// 文件的存放路径

var fullName = path.basename(fpath)
console.log(fullName) // index.html

var nameWithoutExt = path.basename(fpath, '.html')
console.log(nameWithoutExt) // index
```



## 4.path.extname() 的语法格式

```
path.extname(path)
```

path<string>必选参数,表示一个路径的字符串



示例：

```javascript
const fpath ='/a/b/c/index.html'// 路径字符串

const fext = path. extname(fpath)
console.log(fext)// 输出 .html
```

## 3.服务器相关的概念

### 3.1IP地址

**IP地址就是互联网上每台计算机的唯一地址,因此IP地址具有唯一性。**如果把“个人电脑”比作“一台电话”,那么“IP地
址”就相当于“电话号码”,只有在知道对方IP地址的前提下,才能与对应的电脑之间进行数据通信。

IP地址的格式:通常用“点分十进制”表示成(a.b.c.d)的形式,其中,a,b,c,d都是0~255之间的十进制整数。例如:用
点分十进表示的IP地址(192.168.1.1)

- **互联网中每台Web服务器,都有自己的IP地址**,例如:大家可以在Windows的终端中运行ping www.baidu.com命
  令,即可查看到百度服务器的IP地址。

### 3.2 域名和域名服务器

`百度的IP地址：183.2.172.177   对应的 域名：www.baidu.com  `      类比 人类的身份证号(唯一)和姓名

### 4.2 ==req 请求对象==

只要服务器接收到了客户端的请求,就会调用通过server.on()为服务器绑定的request 事件处理函数。

如果想在**事件处理函数中,访问与客户端相关的数据或属性**,可以使用如下的方式:

```javascript
server.on('request', (req) => {
	// req 是请求对象,它包含了与客户端相关的数据和属性,例如:
	// req.ur1 是客户端请求的 URL 地址  ⭐⭐⭐⭐⭐
	// req.method 是客户端的 method 请求类型  ⭐⭐⭐⭐⭐
	const str = 'Your request url is ${req.url}, and request method is ${req.method}
	console.log(str)   // 服务器端（ 自己电脑的终端 显示）
})
```

http://127.0.0.1   —> req.url: /
http://127.0.0.1/index.html  —> req.url: /index.html

### 4.3 ==res 响应对象==

在服务器的request事件处理函数中,如果**想访问与服务器相关的数据或属性**,可以使用如下的方式:

```javascript
server.on('request', (req, res) => {
    // res 是响应对象,它包含了与服务器相关的数据和属性,例如:
    // 要发送到客户端的字符串，客户端呈现的内容 ⭐⭐⭐⭐⭐
    const str = 'Your request url is ${req.url}, and request method is ${req.method}'
    // res.end()方法的作用:
    //向客户端发送指定的内容,并结束这次请求的处理过程。即用户端能看到的内容 ⭐⭐⭐⭐⭐
    res.end(str)
})
```

```javascript
    //发送的内容包含中文
    const str=`您请求的 ur1地址是${req.url},请求的 method 类型是${req.method}`
    // 为了防止中文显示乱码的问题,需要设置响应头 Content-Type 的值为 text/html; charset=utf-8
    res. setHeader('Content-Type', 'text/html; charset=utf-8')
    // 把包含中文的内容,响应给客户端
    res.end(str)
})
```



## 5.根据不同的url响应不同的html内容

### 5.1 基本步骤

🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩

1 获取**请求的url地址**

2 设置**默认的响应内容**为404 Not found

3 判断用户请求的是否为**/或/index.html 首页**

4 判断用户请求的是否为**/about.html关于页面**

5 设置 **Content-Type响应头**,防止中文乱码

6 使用**res.end() 把内容响应给客户端**

🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩🍋‍🟩

```javascript
const http = require('http')
const server = http.createServer()

server.on('request', (req, res) => {
  // 1. 获取请求的 url 地址
  const url = req.url
  // 2. 设置默认的响应内容为 404 Not found
  let content = '<h1>404 Not found!</h1>'
  // 3. 判断用户请求的是否为 / 或 /index.html 首页
  // 4. 判断用户请求的是否为 /about.html 关于页面
  if (url === '/' || url === '/index.html') {
    content = '<h1>首页</h1>'
  } else if (url === '/about.html') {
    content = '<h1>关于页面</h1>'
  }
  // 5. 设置 Content-Type 响应头，防止中文乱码
  res.setHeader('Content-Type', 'text/html; charset=utf-8')
  // 6. 使用 res.end() 把内容响应给客户端
  res.end(content)
})

server.listen(80, () => {
  console.log('server running at http://127.0.0.1')
})
```
