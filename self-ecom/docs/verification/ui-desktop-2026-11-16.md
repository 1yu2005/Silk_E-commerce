# 桌面 UI 优化验收（2026-11-16）

## 改动

- 商城：统一品牌标识、瓷白与森林绿主题、组件配色、导航、首页主视觉、分类筛选、商品信息、详情、登录与顾客业务页面的阅读间距。
- 后台：按工作总览、商品与库存、交易与服务、店铺管理组织权限侧栏；增加当前位置与独立账号操作区，扩大桌面工作区。
- 后台首页：账号摘要、任务入口和业务流程说明；表格、筛选器和表单采用一致的间距与样式。
- 两端增加键盘跳转主内容入口和服装图形 favicon。保留既有窄屏规则，手机端未作专项验收。
- 本次仅修改前端表现层，不更改认证、接口或业务写入逻辑。

## 验证

- 两端 ESLint、TypeScript `--noEmit` 和 Vite 生产构建通过。
- 现有前端测试：132 项通过，0 项失败。
- Playwright 使用生产构建预览；商城公开商品、分类、搜索和商品详情读取本地真实 API。
- 搜索不存在的款式后，显示 0 件商品、无结果说明和重置入口。
- 检查商城首页、商品详情、登录页、后台首页与后台商品列表截图。
- 后台商品列表和商城登录后的商品列表在 1024、1280、1440、1920px 下，页面内容宽度均等于视口宽度，没有横向溢出。
- 后台商品页仅有一个当前菜单高亮；仅具备顾客读取权限时隐藏商品菜单及空的商品与库存分组。
- 商城长昵称、完整账号导航保持在页面宽度内。

## 边界与本地证据

后台登录后的视觉验收、受限权限菜单及商城长昵称使用 Playwright 请求拦截与临时模拟会话，只在独立浏览器会话中生效；未创建真实账号，未提交真实业务操作。这些检查验证布局与菜单展示，不代替后端权限或完整交易链路验收。

本地截图和浏览器验收夹具保存在 `output/playwright/ui-desktop/`，不纳入源码提交。浏览器初次加载存在项目既有的 React Router `HydrateFallback` 警告；最终页面没有资源加载错误。

包管理器在当前沙箱下读取系统临时目录失败，因此使用项目已安装的 ESLint、TypeScript、Vite 及 `node --test` 执行等价检查；没有安装或升级依赖。
