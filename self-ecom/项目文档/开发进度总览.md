首次容器部署的已验证命令（已有`.env`时不要覆盖；失败时停止后续步骤）：

```powershell
docker compose --env-file .env -f infra/compose.yaml config --quiet
docker compose --env-file .env -f infra/compose.yaml build
docker compose --env-file .env -f infra/compose.yaml up -d --wait db
docker compose --env-file .env -f infra/compose.yaml run --rm --no-deps api pnpm --filter @shop/api db:migrate:deploy
docker compose --env-file .env -f infra/compose.yaml run --rm --no-deps api pnpm db:seed:permissions
# 首次空库初始化；密码只从当前进程环境传入该命令，不放入镜像。
$env:INIT_ADMIN_USERNAME = Read-Host '初始化管理员账号'
$env:INIT_ADMIN_PASSWORD = Read-Host '初始化管理员密码' -MaskInput
docker compose --env-file .env -f infra/compose.yaml run --rm --no-deps -e INIT_ADMIN_USERNAME -e INIT_ADMIN_PASSWORD api pnpm db:seed:admin
Remove-Item Env:INIT_ADMIN_PASSWORD
docker compose --env-file .env -f infra/compose.yaml up -d --wait --wait-timeout 90
docker compose --env-file .env -f infra/compose.yaml ps
node infra/verify-compose.mjs
```

本机`.env`通过`API_HOST_PORT=3001`避免与开发API3000冲突；示例默认仍为3000。数据库与上传卷分别为`self-ecom_db_data`、`self-ecom_uploads`，日常操作不执行`down -v`。开发模式与当前容器模式共用开发数据库；集成测试必须使用独立`shop_test`，禁止误指开发库。API镜像已包含Prisma及tsx，关闭pnpm脚本前自动安装；修改依赖后重建镜像，不能在非root运行容器中临时安装。

API及Compose要求有效JWT_SECRET（至少32字节随机密钥），JWT_TTL_SECONDS默认7200；步骤3未改真实`.env`、锁文件、schema及已应用迁移，仅向`.env.example`增加文件配额/限流/清理配置，Compose透传同名变量。图片默认20次/主体/分钟、100张未绑定、300秒清理一批，双Nginx共用配置改为6MiB及代理JSON 413；Docker尚未验证。日常`pnpm dev`运行API及两站。登录/注册限流仍为原固定单实例内存策略，来源按真实连接计算，忽略客户端X-Forwarded-For，经Nginx时同代理共享IP预算；文件频率限制也为单实例内存，多实例需另行设计。

## 6. 每块完成后的维护规则

面向用户的阅读总结：每个板块完成后，将精简总结放在《板块X_开发完成说明.md》的前半部分（8＋9可合并）。用大白话介绍关键目录、本块完成内容、启动或操作验证命令及尚未完成的范围；技术接入与验收依据放在后面，不再单独建立学习总结文档。现有示例为[板块1开发完成说明](开发进度文档/开发完成说明/板块1_开发完成说明.md)及[板块2开发完成说明](开发进度文档/开发完成说明/板块2_开发完成说明.md)。板块2说明已按用户后续指示补齐，先前延期属于历史安排。

1. 在该板块设计文档旁新建对应《板块X_开发完成说明.md》，8＋9合并维护一份；如实际只完成部分，标题或结论标“阶段完成”。
2. 完成说明简述：完成范围、主要代码位置、表与迁移、API、配置/运行命令、测试结果、设计差异、剩余事项及下一块接入点。关联真实Git提交；未提交则明确说明工作区状态。
3. 测试记录写清执行日期、环境、对应提交、命令或Swagger步骤、预期/实际结果及证据位置。区分通过、失败、未执行、待后续补验，不用“已编写测试”代替“执行通过”。

5. 保留历史完成说明及证据，后续补验采用追加记录。设计调整同步需求关联和上下游文档，不只写在聊天里。
